# ممیزی ششم — مسیر جایگزین مستقیم از مرورگر کاربر

تاریخ: ۲۰۲۶-۰۹-۱۸. مبنا: audit5 / `ec123d5`.

## بررسی مسیرهای دیگر

- اتصال TCP به دامنه رسمی OpenRouter برقرار شد، ولی ارتباط پس از ارسال TLS ClientHello، پیش از پاسخ HTTP بسته شد. این مشاهده به‌تنهایی علت نهایی را مشخص نمی‌کند.
- GitHub همچنان پاسخ HTTP 200 می‌دهد؛ پس همه اینترنت قطع نیست.
- دامنه رسمی و `www` بدون ارسال کلید آزمایش شدند؛ هر دو TLS ناموفق. `api.openrouter.ai` در این بررسی DNS نداشت و endpoint جایگزینِ تأییدشده‌ای فرض نشد.
- مرجع رسمی API بررسی شد: https://openrouter.ai/docs/api/reference/overview . مقصد مستندشده همان `https://openrouter.ai/api/v1/chat/completions` است.
- امکان اجرای مستقل روی GitHub Actions بررسی شد؛ اتصال GitHub فعلی برای دریافت کلید عمومی مخزن جهت ذخیره امن secret و مشاهده مجوزهای Actions پاسخ 403 داد. هیچ secret، workflow یا اجرای Actions ایجاد نشد. مخزن عمومی است؛ کلید نباید در کد یا ورودی عمومی workflow گذاشته شود.
- هیچ واسطه ناشناس، تونل، تغییر TLS یا انتقال کلید به مقصد جایگزین انجام نشد.

## ابزار جدید و دلیل آن

`tools/openrouter-browser-check/index.html` یک صفحه مستقل و خودکفا است. وقتی کاربر آن را در مرورگر خودش اجرا می‌کند، fetch به OpenRouter از شبکه همان مرورگر انجام می‌شود، نه از شبکه sandbox. این مسیر جایگزینِ قابل‌آزمایش است، نه اتصال موفقِ ادعاشده.

نسخه پیش‌نمایش فقط فایل‌های این ابزار را روی پورت ۴۱۷۵ سرو می‌کند. هیچ endpoint دریافت/ارسال کلید روی سرور ندارد. کلید قبلیِ موجود در دیتابیس خصوصی عمداً به صفحه عمومی منتقل نشده است؛ کاربر باید آن را در کادر رمز همین صفحه وارد کند. فایل HTML را نیز می‌توان دانلود و محلی باز کرد؛ اگر محدودیت Origin فایل وجود داشت، باید آن پوشه با یک سرور ساده محلی سرو شود.

ابزار کاتالوگ زنده را می‌گیرد، مدل با قیمت صریح صفر انتخاب می‌کند و حداکثر ۱۰ پیام در دو کیس مصنوعی فارسی می‌فرستد. prompt نقش بیمار از موتور همین نسخه استخراج شده؛ تنظیمات اختصاصی مدیر وارد نشده است. تاریخچه هر کیس مستقل است. گزارش شامل مدل درخواست‌شده، مدل پاسخ‌دهنده، وضعیت درخواست‌ها، جواب خام و علامت‌های محدود نیازمند بازبینی انسانی است؛ کلید و خطاهای خام سرویس در گزارش نمی‌آیند.

**این ابزار نمره‌دهی و کنترل خروجی برنامه اصلی را اجرا نمی‌کند.** برای دیدن خطای واقعی مدل، پاسخ خام نگه داشته می‌شود. بنابراین موفقیت آن آزمون کامل بیمار مجازی، درسنامه یا عدالت ارزیابی نیست. نگاشت نقش، طبیعی‌بودن پاسخ و صحت پزشکی همچنان باید انسانی بررسی شوند.

## تدابیر محدودکننده

- فقط مقصد رسمی OpenRouter؛ redirect ممنوع، `credentials: omit` و عدم ارسال referrer؛
- فقط داده مصنوعی، بدون سرویس واسطه و بدون اسکریپت یا فونت خارجی؛
- سقف قیمت ورودی/خروجی صفر، منع جمع‌آوری داده توسط ارائه‌دهنده؛
- ۱۰ درخواست حداکثر، فاصله ۳٫۵ ثانیه، timeout برابر ۴۵ ثانیه، سقف ۲۲۰ توکن و بدون retry؛
- کلید در حافظه صفحه، نه storage یا URL؛ کلید در دانلود گزارش حذف می‌شود؛
- پاسخ مدل فقط با textContent نمایش داده می‌شود؛ HTML، لینک و تصویر مدل اجرا نمی‌شوند؛
- توقف یا پاک‌کردن کلید، درخواست جاری و انتظار بین درخواست‌ها را لغو می‌کند؛
- قیمت خالی یا نامعتبر، مدل پولی، router و هزینه جانبی غیرصفر حذف می‌شوند. این فیلتر محافظه‌کار است و لزوماً همه مدل‌های قابل استفاده رایگان را پوشش نمی‌دهد.

## آزمون‌های واقعاً انجام‌شده

فایل `test.mjs` ابزار، در Chromium واقعی با پاسخ شبکه شبیه‌سازی‌شده اجرا شد. هر **۱۰ گروه بررسی موفق** بودند:

1. حذف مدل پولی، قیمت خالی، router و هزینه جانبی؛ بدون کلید در درخواست کاتالوگ؛
2. عدم ارسال completion بدون کلید؛
3. بودجه دقیق ۱۰ درخواست و سیاست قیمت/جمع‌آوری داده؛
4. نمایش HTML مخرب به‌صورت متن، بدون درخواست به مقصد مهاجم؛ حذف کلید از پاسخ و گزارش؛
5. نبود localStorage/sessionStorage؛
6. دانلود JSON؛
7. توقف روی ۴۰۱ بدون retry یا completion ساختگی؛
8. توقف روی خطای شبکه؛
9. توقف روی نبود متن نهایی معتبر؛
10. پاک‌کردن کلید و لغو ادامه آزمون.

این ۱۰ گروه، تست‌های مرورگری مستقل‌اند، نه ۱۰ تست جدید Vitest بک‌اند. خروجی شبکه این بررسی‌ها mock بوده است؛ **هیچ completion واقعی OpenRouter در این دور دریافت نشد**. اجرای واقعی از شبکه کاربر هنوز نیازمند بازکردن ابزار و شروع آزمون در مرورگر اوست. گزارش حاصل را می‌توان بدون کلید برای تحلیل خطاها تحویل داد.

یک probe اضافی بدون mock از مرورگر sandbox، با ابزار جدید و بدون کلید، نیز اجرا شد. دریافت کاتالوگ با خطای عمومی Network/CORS شکست خورد و هیچ completion ارسال نشد. این مشاهده درباره شبکه sandbox است، نه شبکه مرورگر کاربر.

## وضعیت برنامه و انتشار

کد بیمار مجازی اصلی، بانک‌ها، تنظیمات انتشار و کلاینت ساخته‌شده تغییری نکردند. مجموعه backend/client دوباره اجرا نشد؛ نتایج قبلی به همان دور مربوط‌اند. این نسخه ابزار تشخیص و مسیر اجرای جایگزین اضافه می‌کند، نه رفع خودکار تمام باگ‌ها. مشکلات بالینی و نمره‌دهی گزارش‌های قبل همچنان بازند.
