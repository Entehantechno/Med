# 💾 پایداری دیتابیس + 📥 ورود دسته‌جمعی سوالات

## بخش ۱ — دیتابیس دائمی (دیتا با تغییر کد پاک نمی‌شود)

از این نسخه، دیتابیس شما **کاملاً پایدار** است:

- **بار اول** که سایت را اجرا می‌کنید، به‌طور خودکار محتوای اولیه (نمونه) بارگذاری می‌شود.
- **دفعات بعد** — حتی اگر کد سایت را تغییر دهید و دوباره اجرا کنید — **هیچ داده‌ای پاک نمی‌شود**. حساب کاربران، آزمون‌ها، فلش‌کارت‌ها، نتایج، امتیازها و همه‌چیز باقی می‌ماند.
- هنگام خاموش‌شدن سرور، آخرین تغییرات به‌صورت ایمن روی دیسک ذخیره می‌شوند (بدون از دست رفتن رکورد).

### دستورها
```bash
cd server
npm install
npm start          # ← همین کافی است؛ بار اول خودش seed می‌کند، بعد دیتا حفظ می‌شود
```
دیگر لازم نیست `npm run seed` بزنید.

> 🛡️ **محافظت:** دستور `npm run seed` اگر ببیند دیتابیس داده دارد، **از اجرا خودداری می‌کند** تا اشتباهی داده‌ها پاک نشوند. 
> اگر عمداً خواستید همه‌چیز را پاک و از نو بسازید:
> ```bash
> npm run seed:reset      # ⚠️ همه‌چیز را پاک می‌کند
> ```

### پشتیبان‌گیری
کل دیتابیس در یک فایل است: `server/medlab.db`. برای بکاپ فقط کافی است این فایل را کپی کنید؛ برای بازگردانی، جایگزینش کنید.

## بخش ۲ — ورود دسته‌جمعی سوالات پره‌انترنی

از پنل مدیریت، بخش **«حساب‌های کاربران» → «مدیریت محتوا» → «ورود دسته‌جمعی سوالات»** می‌توانید صدها سوال را یک‌جا از فایل **CSV** وارد کنید.

### ویژگی‌ها
- پشتیبانی از **همهٔ انواع سوال**: چهارگزینه‌ای، درست/غلط، جای خالی، تطبیق جفت‌ها، مرتب‌سازی.
- **درسنامهٔ QB** برای هر سوال: نکتهٔ طلایی، بررسی تک‌تک گزینه‌ها، منبع، و هینت پلکانی.
- **انتساب به درس**: با ستون `topic` هر سوال به درس مربوطه (مثل `gi`, `cardio`, `surgery`) وصل می‌شود و **خودکار در مسیر یادگیری** آن درس قرار می‌گیرد.
- **پیش‌بینی و اعتبارسنجی**: قبل از وارد کردن، خطاها و تعداد هر نوع سوال نمایش داده می‌شود.

### قالب فایل
- از دکمهٔ **«دانلود قالب نمونه»** یک فایل CSV آماده با یک نمونه از هر نوع سوال بگیرید.
- یا فایل `نمونه-ورود-سوالات.csv` در همین پوشه را ببینید.

### ستون‌های مهم CSV
| ستون | توضیح |
|---|---|
| `type` | نوع سوال: `mcq` \| `truefalse` \| `fill` \| `match` \| `order` |
| `topic` | اسلاگ درس: `gi, pulmo, nephro, heme, endo, rheum, cardio, surgery, peds, obgyn, path, infect, neuro, psych, derm, ortho, pharm, uro, ophth, ent, radio, stats, ethics, genetics, immuno, nutrition, physics` |
| `difficulty` | `easy` \| `medium` \| `hard` |
| `q_fa` / `q_en` | متن سوال (فارسی/انگلیسی) |
| `options_fa` / `options_en` | گزینه‌ها با جداکنندهٔ `\|` (برای چهارگزینه‌ای) |
| `correct` | شمارهٔ گزینهٔ درست (۱ به بعد) — برای چهارگزینه‌ای |
| `answer` | `true` \| `false` — برای درست/غلط |
| `blank_fa` / `accept_fa` | پاسخ جای خالی و پاسخ‌های جایگزین (با `\|`) |
| `pairs_fa` | جفت‌ها به شکل `چپ::راست` با جداکنندهٔ `\|` — برای تطبیق |
| `items_fa` | آیتم‌ها به ترتیب درست با `\|` — برای مرتب‌سازی |
| `golden_fa` / `golden_en` | نکتهٔ طلایی |
| `analysis_fa` | بررسی گزینه‌ها با `\|` (مثل `✅ گزینه ب درست\|❌ گزینه الف`) |
| `source_fa` | منبع/شناسنامه |

> ⚖️ **توجه حقوقی:** سوالات رسمی آزمون‌های پره‌انترنی دارای حق نشر هستند. این ابزار به شما امکان می‌دهد سوالاتی را که **خودتان حق استفاده از آن‌ها را دارید** (از منابع مجاز) وارد کنید. مسئولیت محتوای واردشده با شماست.
