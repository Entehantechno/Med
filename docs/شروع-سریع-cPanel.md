# 🚀 راه‌اندازی MED School روی هاست فریم‌ورک پلاس (cPanel + Node.js)

این راهنما مخصوصِ همین حالتِ توست: **cPanel داری، Node.js دارد، و کلاینت از قبل ساخته شده** (پس نیازی به build روی هاست نیست).
فایلِ موردِ نیازت: **`MED-School.zip`** (همین که تحویل گرفتی).

کلِ کار ۶ گام است و حدود ۱۰ دقیقه طول می‌کشد.

---

## گام ۱ — آپلود و استخراج فایل
۱. وارد **cPanel** شو.
۲. **File Manager** را باز کن.
۳. کنارِ `public_html` یک پوشهٔ جدید بساز به نامِ `medschool`.
۴. واردِ پوشهٔ `medschool` شو و `MED-School.zip` را **Upload** کن.
۵. روی فایلِ زیپ راست‌کلیک → **Extract**.
۶. بعد از استخراج، زیپ را می‌توانی پاک کنی. (باید مستقیم پوشه‌های `server`، `client`، و فایلِ `package.json` را داخلِ `medschool` ببینی.)

---

## گام ۲ — تنظیمات (`.env`) — هیچ کاری لازم نیست ✅
فایل `.env.ready` داخل زیپ از قبل برای **medschool.ir** آماده است (`APP_URL=https://medschool.ir`، حالت production).
در اولین اجرا، سرور خودش آن را به `.env` کپی می‌کند و یک `JWT_SECRET` تصادفیِ مخصوص همین هاست می‌سازد.
- دیتابیس و آپلودها به‌طور خودکار در پوشهٔ `~/medschool-data` (کنارِ پوشهٔ برنامه، بیرون از کد) ساخته می‌شود؛ پس با آپدیت‌های بعدی پاک نمی‌شود.
- فقط اگر دامنه‌ات چیز دیگری است، `.env.ready` را باز کن و `APP_URL` را عوض کن.

## گام ۳ — ساختِ اپلیکیشن Node.js
۱. در cPanel در کادرِ جستجوی بالا تایپ کن `node` → **Setup Node.js App** را باز کن → **Create Application**.
۲. مقادیر را این‌طور بگذار:
   - **Node.js version:** `20` (یا بالاترین نسخهٔ موجود)
   - **Application mode:** `Production`
   - **Application root:** `medschool`
   - **Application URL:** دامنه‌ات را انتخاب کن
   - **Application startup file:** `app.cjs`  ← (نه `server/src/index.js`؛ آن فایل ES-Module است و Passenger نمی‌تواند مستقیم اجرایش کند)
۳. **Create** را بزن.

---

## گام ۴ — نصبِ پکیج‌ها (فقط یک کلیک)
> ✅ چون کلاینت از قبل ساخته شده، فقط پکیج‌های سرور نصب می‌شوند — سریع و سبک.

۱. در همان صفحهٔ Node.js App، پایین‌تر دکمهٔ **Run NPM Install** را بزن و صبر کن تمام شود (چند دقیقه).
   - این دستور خودش پکیج‌های سرور را هم نصب می‌کند. کارِ دیگری لازم نیست.

---

## گام ۵ — Restart و باز کردنِ سایت
۱. بالای صفحهٔ Node.js App → **Restart** (یا Stop سپس Start).
۲. دامنه‌ات را در مرورگر باز کن. سایت باید بالا بیاید! 🎉
   - بارِ اول، محتوای نمونه به‌طور خودکار ساخته می‌شود (فقط همان یک‌بار).

---

## گام ۶ — ورود و امن‌سازی
- برو به دامنه‌ات → دکمهٔ ورود → با این وارد شو:
  - نام کاربری: `admin` — رمز: `demo`
- 🔴 **بلافاصله بعد از ورود، از بخشِ پروفایل/تنظیمات رمزِ ادمین را عوض کن.**
- کاربرانِ نمونهٔ دیگر (برای تست): `teacher` / `learner` / دانشجو `40012345` — همه رمز `demo`. بعداً می‌توانی از پنلِ ادمین حذف/غیرفعالشان کنی.

---

## اگر چیزی درست کار نکرد (رفعِ اشکالِ سریع)
- **صفحه سفید یا خطا:** برگرد به Setup Node.js App → مطمئن شو **startup file** دقیقاً `app.cjs` است → **Restart**.
- **صفحهٔ «در حالِ آماده‌سازی…»:** طبیعی است؛ فقط در **اولین اجرا** (ساختِ دیتابیس و واردکردنِ ۱۱٬۶۰۰ سؤال) حدود ۱ تا ۲ دقیقه طول می‌کشد و صفحه خودش تازه می‌شود. ری‌استارت‌های بعدی زیرِ ۱ ثانیه‌اند. وضعیت: `https://medschool.ir/api/health` → `"ready":true`.
- **بازهم ۵۰۳ / Passenger error:** در File Manager فایلِ `stderr.log` داخلِ پوشهٔ برنامه (`medschool`) را باز کن؛ آخرین خطوطش علت را می‌گوید. اگر `ERR_REQUIRE_ESM` دیدی یعنی startup file هنوز `server/src/index.js` است — به `app.cjs` تغییر بده. اگر `Cannot find module` دیدی، **Run NPM Install** را دوباره بزن.
- **پیامِ «Client not built»:** یعنی پوشهٔ `client/dist` آپلود نشده. زیپ را کامل دوباره Extract کن (این پوشه داخلِ زیپ هست).
- **خطای نصب/کمبودِ رم موقع npm install:** دوباره Run NPM Install را بزن؛ اگر باز نشد، از پشتیبانی بخواه برای لحظهٔ نصب رم را موقتاً بالا ببرد. (اجرای خودِ سایت رمِ کمی می‌خواهد — فقط نصب گاهی سنگین است.)
- **SSL/HTTPS:** از بخشِ **SSL/TLS Status** در cPanel گواهیِ رایگان (AutoSSL) را برای دامنه‌ات فعال کن.

---

## آپدیت‌های بعدی (وقتی نسخهٔ جدید دادم)
۱. فقط فایل‌های `server` و `client` را با نسخهٔ جدید جایگزین کن (پوشهٔ `.env` و `DATA_DIR` را دست نزن).
۲. **Run NPM Install** → **Restart**.
۳. چون `DATA_DIR` بیرون از کد است، **همهٔ دیتای کاربرانت سالم می‌ماند.** ✅

> نکتهٔ طلایی: قبل از هر آپدیت، از پنلِ ادمین (بخشِ ابزارهای داده/Backup) یک بکاپ بگیر.
