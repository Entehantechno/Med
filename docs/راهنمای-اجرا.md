# 🧪 راهنمای اجرای MED Lab (پلتفرم هوشمند آموزش پزشکی)

این راهنما دو حالت را پوشش می‌دهد:
۱) **اجرای لوکال** روی کامپیوتر خودتان (برای توسعه و تست)
۲) **اجرا روی سرور/دامنه** (برای استفاده واقعی و در دسترس قرار دادن روی اینترنت)

---

## 🧩 پیش‌نیازها

- **Node.js نسخه ۱۸ یا بالاتر** (نسخه ۲۰ توصیه می‌شود) — از [nodejs.org](https://nodejs.org) نصب کنید.
- برای بررسی نصب:
  ```bash
  node -v      # باید مثلاً v20.x نمایش دهد
  npm -v
  ```
- (اختیاری) **Git** برای دریافت پروژه.

> نکته: این پروژه از دیتابیس **SQLite** استفاده می‌کند که فایل‌محور است و **نیازی به نصب دیتابیس جداگانه ندارد**.

# بخش ۱ — اجرای لوکال (روی کامپیوتر شخصی)

## گام ۱: ورود به پوشه پروژه
```bash
cd medlab-fullstack
```

## گام ۲: نصب وابستگی‌های بک‌اند (سرور)
```bash
cd server
npm install
```

## گام ۳: ساخت فایل تنظیمات محیطی
فایل نمونه را کپی کنید:
```bash
cp .env.example .env
```
سپس فایل `.env` را باز کرده و مقدار `JWT_SECRET` را به یک عبارت تصادفی و محرمانه تغییر دهید:
```
PORT=4000
JWT_SECRET=یک-عبارت-تصادفی-طولانی-و-محرمانه
```
> کلید هوش مصنوعی را می‌توانید همین‌جا یا بعداً از داخل **پنل مدیریت** وارد کنید.

## گام ۴: پر کردن دیتابیس با داده اولیه (Seed)
```bash
npm run seed
```
این دستور کاربران و محتوای نمونه را می‌سازد.

## گام ۵: نصب و ساخت فرانت‌اند (کلاینت React)
از پوشه `server` به پوشه `client` بروید:
```bash
cd ../client
npm install
npm run build
```
با `npm run build` نسخه نهایی و بهینه‌شده فرانت‌اند در پوشه `client/dist` ساخته می‌شود.

## گام ۶: اجرای سرور
```bash
cd ../server
npm start
```
اکنون در مرورگر باز کنید:
```
http://localhost:4000
```
سرور هم API و هم رابط کاربری را روی همین یک آدرس ارائه می‌دهد. 🎉

---

## 🔁 حالت توسعه (Hot Reload) — اختیاری
اگر می‌خواهید هنگام تغییر کد، صفحه به‌صورت خودکار به‌روزرسانی شود، به‌جای گام ۵ و ۶ از **دو ترمینال جدا** استفاده کنید:

**ترمینال اول (سرور):**
```bash
cd server
npm run dev
```
**ترمینال دوم (کلاینت):**
```bash
cd client
npm run dev
```
سپس آدرس **http://localhost:5173** را باز کنید (درخواست‌های API به‌صورت خودکار به پورت ۴۰۰۰ هدایت می‌شوند).

# بخش ۱.۵ — اجرای سریع با Docker (ساده‌ترین روش) 🐳

اگر **Docker** نصب دارید، کل سامانه با یک دستور بالا می‌آید (نیازی به نصب Node یا اجرای دستی مراحل نیست):

```bash
cd medlab-fullstack
docker compose up --build
```

سپس آدرس **http://localhost:4000** را باز کنید. بار اول دیتابیس به‌صورت خودکار seed می‌شود.

- دیتابیس و تصاویر آپلودشده در یک والیوم دائمی (`medlab-data`) ذخیره می‌شوند و با ری‌استارت پاک نمی‌شوند.
- برای اتصال هوش مصنوعی واقعی، متغیرها را قبل از اجرا تنظیم کنید یا از پنل مدیریت وارد کنید:
  ```bash
  JWT_SECRET="یک-عبارت-محرمانه" AI_PROVIDER="OpenRouter" AI_API_KEY="or-..." AI_MODEL="openai/gpt-4o" docker compose up --build
  ```
- توقف: `docker compose down` — حذف کامل داده‌ها: `docker compose down -v`

## 🔬 فلش‌کارت‌های پیشرفته (سؤال تصویری/متنی/ترکیبی + سرچ‌باکس)

هنگام ساخت فلش‌کارت در پنل مدیریت می‌توانید انتخاب کنید:
- **نوع سؤال:** تصویری، متنی، یا ترکیبی (تصویر + متن).
- **نوع پاسخ‌دهی:**
  - **چندگزینه‌ای:** دانشجو یک گزینه را انتخاب می‌کند.
  - **جستجویی (Autocomplete):** یک **سرچ‌باکس حرفه‌ای** که دانشجو تایپ می‌کند و گزینه مطابق را از فهرست فیلترشده انتخاب می‌کند (تطبیق فازی، دوزبانه، پیمایش با کیبورد ↑ ↓ Enter) — تا خطای تایپ اصلاً مشکل‌ساز نشود.
- دانشجو ابتدا یک **درس (Deck)** را برای تمرین انتخاب می‌کند یا همه را تمرین می‌کند.

## 👤 پروفایل و تغییر رمز

هر کاربر از دکمه 👤 در نوار بالا به صفحه **پروفایل** می‌رود و می‌تواند رمز عبور خود را تغییر دهد (با تأیید رمز فعلی). دانشجو نمودار روند نمرات خود را نیز می‌بیند.

## 📊 داشبورد گرافیکی

داشبورد مدیریت شامل **نمودار روند نمرات**، **نمودار دایره‌ای فعالیت** و **نمودار توزیع نمرات** است (بدون هیچ کتابخانه خارجی).

## 📥 ورود و خروج گروهی با CSV (Import/Export)

در پنل مدیریت، بخش **بانک بیماران** و **فلش‌کارت‌ها** دکمه‌های «ورود از CSV» و «خروجی CSV» دارند:
- **خروجی CSV:** همه‌ی کیس‌ها یا فلش‌کارت‌ها را در یک فایل اکسل‌خوان دریافت کنید (با پشتیبانی از فارسی).
- **ورود CSV:** برای افزودن یک‌باره‌ی چند کیس/فلش‌کارت، ابتدا یک خروجی بگیرید تا ستون‌ها را ببینید، سپس ردیف‌های جدید را اضافه و فایل را وارد کنید.
- برای فلش‌کارت، گزینه‌ها در ستون `options_en`/`options_fa` با علامت `|` جدا می‌شوند و پاسخ صحیح در `correct_en`/`correct_fa` مشخص می‌شود.

> نکته امنیتی: **تنظیمات هوش مصنوعی و مدیریت Prompt فقط در اختیار ادمین است** (استاد به آن‌ها دسترسی ندارد).

## 🩻 بارگذاری تصاویر پزشکی (رادیولوژی/پاتولوژی/بافت‌شناسی)

- در **پنل مدیریت ← بانک بیماران ← ویرایش کیس**، بخش «تصاویر پزشکی» را باز کنید، روی **افزودن تصویر** بزنید و فایل را بارگذاری کنید (هر تصویر یک برچسب فارسی/انگلیسی دارد).
- در **فلش‌کارت‌ها** نیز می‌توانید برای هر کارت یک تصویر بارگذاری کنید.
- دانشجو هنگام آزمون، تصاویر کیس را در تب **تصاویر** می‌بیند.
- فقط استاد/مدیر اجازه بارگذاری دارد؛ فقط فرمت‌های تصویری و حداکثر ۸ مگابایت پذیرفته می‌شود.

# بخش ۲ — اجرا روی سرور و دامنه (Production)

فرض می‌کنیم یک سرور مجازی (VPS) با سیستم‌عامل **Ubuntu** و یک **دامنه** (مثلاً `medlab.example.com`) دارید.

## گام ۱: اتصال به سرور و نصب Node.js
```bash
ssh root@آدرس-آی‌پی-سرور

# نصب Node.js نسخه ۲۰
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs git
node -v
```

## گام ۲: انتقال پروژه به سرور
یا با Git کلون کنید، یا پوشه پروژه را با `scp` آپلود کنید:
```bash
# روش scp از روی کامپیوتر خودتان:
scp -r medlab-fullstack root@آدرس-آی‌پی:/var/www/medlab
```
سپس روی سرور:
```bash
cd /var/www/medlab
```

## گام ۳: نصب، تنظیمات و ساخت
```bash
# بک‌اند
cd server
npm install --omit=dev
cp .env.example .env
nano .env        # مقدار JWT_SECRET را حتماً تغییر دهید و PORT=4000 بماند
npm run seed

# فرانت‌اند
cd ../client
npm install
npm run build
```

## گام ۴: اجرای دائمی سرور با PM2
`PM2` سرور را در پس‌زمینه نگه می‌دارد و پس از ری‌استارت سرور دوباره اجرا می‌کند:
```bash
sudo npm install -g pm2
cd /var/www/medlab/server
pm2 start ../app.cjs --name medlab
pm2 save
pm2 startup      # دستور نمایش‌داده‌شده را اجرا کنید تا با روشن شدن سرور، اپ خودکار بالا بیاید
```
بررسی وضعیت:
```bash
pm2 status
pm2 logs medlab
```

## گام ۵: اتصال دامنه با Nginx (Reverse Proxy)
نصب Nginx:
```bash
sudo apt-get install -y nginx
```
یک فایل تنظیمات بسازید:
```bash
sudo nano /etc/nginx/sites-available/medlab
```
محتوای زیر را قرار دهید (دامنه خود را جایگزین کنید):
```nginx
server {
    listen 80;
    server_name medlab.example.com;

    location / {
        proxy_pass http://localhost:4000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```
فعال‌سازی و بارگذاری مجدد:
```bash
sudo ln -s /etc/nginx/sites-available/medlab /etc/nginx/sites-enabled/
sudo nginx -t          # بررسی صحت تنظیمات
sudo systemctl reload nginx
```
> پیش از این مرحله مطمئن شوید رکورد **A** دامنه در پنل DNS به **آی‌پی سرور** اشاره می‌کند.

## گام ۶: فعال‌سازی HTTPS رایگان (SSL)
```bash
sudo apt-get install -y certbot python3-certbot-nginx
sudo certbot --nginx -d medlab.example.com
```
Certbot گواهی SSL را نصب و تمدید خودکار را تنظیم می‌کند. حالا سایت روی:
```
https://medlab.example.com
```
در دسترس است. ✅

## 🤖 اتصال هوش مصنوعی واقعی (پس از اجرا)

1. با حساب **admin** یا **teacher** وارد شوید.
2. به بخش **پنل مدیریت → تنظیمات هوش مصنوعی** بروید.
3. سرویس‌دهنده را انتخاب کنید (مثلاً **OpenRouter**، **Groq**، **DeepSeek**، **OpenAI** و …).
   - آدرس پایه (Base URL) به‌صورت خودکار پر می‌شود.
4. نام **مدل** و **کلید API** را وارد کنید.
5. روی **تست اتصال** بزنید.

> اگر کلیدی وارد نکنید، سامانه به‌طور خودکار از موتور شبیه‌سازی داخلی (mock) استفاده می‌کند و همه‌چیز آفلاین کار می‌کند.

## 🏫 ساخت کلاس درس و نمره‌دهی کلاسی (جایگزین لاگ‌بوک)

۱. با حساب **admin** یا **teacher** وارد شوید و به **پنل مدیریت ← کلاس‌های درسی** بروید.
۲. روی **کلاس جدید** بزنید، نام و توضیحات را وارد کنید و **حداکثر دفعات مجاز** برای هر کیس را تعیین کنید. یک **کد کلاس** به‌صورت خودکار ساخته می‌شود.
۳. روی **کارنامه کلاس** بزنید تا وارد صفحه مدیریت کلاس شوید:
   - **مدیریت کیس‌ها:** کیس‌های موردنظر را انتخاب کنید و برای هرکدام **ضریب (وزن)** در نمره کلاسی مشخص کنید.
   - **مدیریت دانشجویان:** دانشجویان عضو کلاس را انتخاب کنید.
۴. دانشجو پس از ورود، در بخش **کلاس‌های درسی** فقط کلاس‌هایی را می‌بیند که عضو آن است. با انجام کیس‌های کلاس، به‌جای لاگ‌بوک سنتی، **نمره کلاسی** (میانگین وزن‌دار بهترین نمرات) کسب می‌کند.
۵. استاد در **کارنامه کلاس** پیشرفت و نمره هر دانشجو را به‌صورت زنده می‌بیند.

> دانشجویی که عضو کلاس نباشد، به هیچ‌وجه به کیس‌های آن کلاس دسترسی ندارد.

## ➕ افزودن دانشجو برای یک آزمون خاص (توسط ادمین)

1. پنل مدیریت → **کاربران** → دکمه **افزودن دانشجو**.
2. **شماره دانشجویی** را وارد کنید (همین به‌عنوان نام کاربری استفاده می‌شود).
3. اگر رمز عبور را خالی بگذارید، رمز پیش‌فرض = همان شماره دانشجویی خواهد بود.
4. آزمون‌های مجاز را از فهرست تیک بزنید و **حداکثر دفعات مجاز** را تعیین کنید.
5. ذخیره کنید. دانشجو فقط به همان آزمون‌ها دسترسی خواهد داشت؛ سایر آزمون‌ها برایش قابل مشاهده و اجرا نیستند.

برای تغییر بعدی دسترسی‌ها از دکمه **مدیریت دسترسی** روبه‌روی هر دانشجو استفاده کنید.

## 🛠️ عیب‌یابی سریع

| مشکل | راه‌حل |
|---|---|
| صفحه سفید است | مطمئن شوید `npm run build` در پوشه `client` اجرا شده باشد. |
| خطای پورت اشغال است | مقدار `PORT` در `.env` را تغییر دهید یا فرآیند قبلی را ببندید. |
| دانشجو آزمونی نمی‌بیند | از پنل مدیریت به او آزمون تخصیص دهید. |
| هوش مصنوعی پاسخ ثابت می‌دهد | یعنی موتور mock فعال است؛ کلید API را در تنظیمات وارد کنید. |
| بازنشانی کامل داده | فایل `server/medlab.db` را حذف و دوباره `npm run seed` را اجرا کنید. |
