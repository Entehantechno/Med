# راهنمای جست‌وجو (بانکِ سؤال و پنلِ ادمین)

از v73 یک موتورِ جست‌وجوی مشترک در سرور (`server/src/lib/textsearch.js`) و یک جعبهٔ جست‌وجوی مشترک در کلاینت (`client/src/components/SearchBox.jsx`) استفاده می‌شود.

## دستورِ جست‌وجو
| می‌نویسید | معنی |
|---|---|
| `آسم درمان` | هر دو واژه باید در سؤال باشند (AND) |
| `"فشار خون"` | عبارتِ دقیق |
| `-کودک` | سؤال‌هایی که این واژه را دارند حذف می‌شوند |
| `سال:1402` / `year:1402` | فقط سؤال‌های آن سال |
| `ماه:شهریور` / `month:` | ماهِ آزمون |
| `درس:قلب` / `subject:` | درسِ آزمون |
| `فصل:آریتمی` / `chapter:` | فصل |
| `مفهوم:…` / `concept:` | مفهوم |
| `آزمون:دستیاری` / `exam:` | نوعِ آزمون (دستیاری/پره‌انترنی) |
| `سبک:کیس` / `style:` | سبکِ سؤال (کیس، دانشی، منفی، تصویری) |
| `#1234` | سؤال با شمارهٔ مشخص |

نرمال‌سازی خودکار: ي/ی، ك/ک، ة/ه، انواعِ همزه، اعراب، نیم‌فاصله، ارقامِ فارسی/عربی/لاتین — پس «كليه» همان «کلیه» است.

## بانکِ سؤال (پریمیوم)
- پیشنهادِ زنده حین تایپ: فصل/درس/مفهوم/آزمون (با تعداد) + چند صورتِ سؤال. انتخابِ فصل = اعمالِ فیلتر.
- فیلترها چندانتخابی‌اند: داخلِ یک بُعد «یا»، بینِ بُعدها «و». تعدادها زنده به‌روز می‌شوند.
- چیپ‌های بالای نتایج فیلترهای فعال را نشان می‌دهند؛ ✕ هر چیپ همان فیلتر را برمی‌دارد.
- مرتب‌سازی: با متنِ جست‌وجو «مرتبط‌ترین» پیش‌فرض است؛ بدونِ متن «جدیدترین آزمون».
- آدرسِ صفحه (`#browse?q=…&subject=…`) قابلِ اشتراک است و با رفرش حفظ می‌شود.
- میان‌برها: `/` فوکوس روی جعبه، `↑/↓` حرکت در پیشنهادها، `Enter` انتخاب، `Esc` بستن، `?` راهنما.

## پنلِ ادمین
- همهٔ جدول‌ها (`DataTable`) همان دستور (`-حذف`، `"عبارت"`) را با نرمال‌سازیِ فارسی می‌فهمند و نتیجه را هایلایت می‌کنند.
- «مدیریتِ محتوا» علاوه بر متنِ سؤال، در درس/فصل/مفهوم/آزمون/نوع و `#id` هم می‌گردد.
- API: `GET /api/admin/learn-cards?lang=fa&q=…&sort=relevance&page=1&per=200` → `total`, `matched`, `cards[].hl`.

## API بانک
- `GET /api/learn/browse?lang=fa&q=…&subject=a,b&year=1402&sort=relevance&page=1&per=20`
  → `total`, `bankTotal`, `sort`, `query` (تجزیهٔ عبارت), `cards[]` (با `hl` = بازه‌های هایلایت), `facets`.
- `GET /api/learn/browse/suggest?lang=fa&q=قل` → `suggestions[]` با `kind` ∈ subject/chapter/concept/exam/card.
