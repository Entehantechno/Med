### مرحلهٔ ۲الف (کامیت `2b23c13` و تغییرات این انتشار)
- **نمودارهای داشبورد مدیر/مدرس:** SVG نمودار خطی ارتفاع ۶۲۰px داشت و کارت‌ها را تا پایین صفحه می‌کشید. حالا ارتفاع ثابت ۱۳۰px است (`components/Charts.jsx`).
- **نوار بالا:** نام کاربر، زبان، تم و خروج ۴۴px ارتفاع دارند.
- **زبانهٔ پشتیبانی:** ظاهرِ ۲۶px حفظ شد، ولی ناحیهٔ لمس با یک pseudo-element به ۴۴px رسید. قاعدهٔ سراسری موبایل که دکمه‌ها را ۴۴px عرض می‌داد، زبانه را روی نوار پایین می‌انداخت؛ این مشکل برطرف شد.
- **مسیر یادگیری:** اموجی‌های تزئینی (👑 🏆 💪 📘 🚀 🔒 📚 ✓) با آیکن جایگزین شدند. ۴۰ آیکن موضوعی (`icon` در داده) عمداً دست‌نخورده ماندند.
- **CSS تکراری:** در `styles.css` قواعد تکراری برای `.weak-row` و `.has-mobile-tabbar .support-fab/.toast/.pwa-install` حذف شد (همان مقدار در `mobile-learn.css` باقی است).
- **بودجهٔ CSS:** کل CSS از ۶۵.۹۹۶ KB (سقف ۶۶) پاس می‌شود. برای این کار قاعدهٔ `tabular-nums` برای عددهای کارت آمار حذف شد (اثر بصری کم بود) و چند تکرار جزئی در CSS پاک شد.

- `npm run perf:budget`: CSS پاس. **JS ورودی ۲۶.۷۹ KB در برابر سقف ۲۵ KB رد می‌شود.** این مشکل از HEAD (۲۶.۵۸ KB) به ارث رسیده و در این انتشار تغییر نکرده است.
- ۱۳۶۶px و ۳۷۵px: بررسی بصری شد. در ۳۷۵px هدر و زبانه درست قرار دارند.
- ممیزی خودکار صفحهٔ دانشجو: هدف‌های لمسی کوچک از ۳ به ۱ رسید (زبانه، که ناحیهٔ لمسش ۴۴px است).
