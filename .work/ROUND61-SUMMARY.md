# جمع‌بندی دور ۶۱ — بازبینی باقی‌ماندهٔ بانک سؤال

**تاریخ:** ۲۰۲۶-۰۹-۲۴  
**درخواست کاربر:** بازبینی باقی‌ماندهٔ بانک سؤال  
**نوع دور:** پژوهش و بازبینی فقط؛ بدون اعمال در payload

## دامنهٔ تکمیل‌شده

این دور، تنها گروهی را که پس از دور ۶۰ هنوز به بررسی عمیق‌تری نیاز داشت پوشش داد: **۲۷ ردیف BROKEN** دور ۵۹. این ردیف‌ها دوباره با متن فعلی، گزینه‌ها، وضعیت رسانه، تاریخچهٔ محلی و راهنماهای بالینی سنجیده شدند.

## نتیجهٔ ۲۷ ردیف BROKEN

| مسیر نهایی | تعداد | نتیجه |
| --- | ---: | --- |
| بازیابی منبع اولیه | ۱۳ | جدول، نمودار، شجره‌نامه، گاز خون، اسپرموگرام یا پایان متن غایب است؛ حدس‌زدن ممنوع است. |
| بازنویسی تحریریه‌ای اساسی | ۱۲ | گزینه‌ها یا صورت سؤال پاسخ یکتا نمی‌سازند. |
| رفع تکرار گزینه، بدون تغییر کلید | ۱ | `25:136`؛ دورهٔ واگیری سرخک از کلید فعلی پشتیبانی می‌کند، اما دو گزینهٔ نادرست یکسان‌اند. |
| پیشنهاد شواهدی، اعمال‌نشده | ۱ | `25:96 → 1`؛ زوستر موضعی مادر معمولاً VZIG روتین نوزاد نمی‌خواهد و مسیر ضدویروس خوراکی مادر محتمل است؛ زمان شروع و وضعیت مادر باید مستقل بررسی و مجوز کاربر گرفته شود. |
| **جمع** | **۲۷** | هیچ تغییر داده‌ای انجام نشد. |

## کنترل بازیابی منبع

- برای هر ۱۳ ردیف وابسته به منبع، جایگاه‌های `image`، `media` و `micro.media` در payload فعلی دوباره بررسی شدند؛ همه خالی‌اند.
- رسانه‌های محلی موجود به دفترچه‌های ۱۴۰۲ و ۱۴۰۳ تعلق دارند و نگاشت قابل اثباتی به این شناسه‌ها یا نسخهٔ ۰۰۵ ندارند.
- جست‌وجوی تاریخچهٔ Git برای عبارت‌های نمونه فقط payloadها، fixtureها و گزارش‌های قبلی را یافت؛ اسکن یا صفحهٔ منبع اولیه پیدا نشد.
- یک نمایهٔ رسمی دفترچهٔ شهریور ۱۳۹۸ یافت شد، اما چون نسخه/تاریخ متناظر برای رکوردهای فعلی اثبات نشده است، هیچ داده‌ای از آن وارد بررسی یا بانک نشد.

## حفاظت از بانک

هیچ فیلدی در داده‌های قانونی بانک تغییر نکرده است:

- `question_fa`
- `options_fa`
- `correct_index`
- `explanation_fa`
- `options_why_fa`
- `micro`
- `image`، `media` و `micro.media`

برای هر یک از ۲۷ ردیف، اثرانگشت `SHA-256` از متن، گزینه‌ها، کلید و علت نقص ثبت شده است.

## اعتبارسنجی اجراشده

```text
python3 .work/round61-remaining-review/test_round61_remaining_review.py
Ran 8 tests ... OK
```

آزمون‌ها تأیید می‌کنند که:

1. اجرای مولد، payloadهای مرتبط را تغییر نمی‌دهد.
2. دقیقاً همان ۲۷ ردیف دور ۵۹، هر کدام یک‌بار پوشش داده شده‌اند.
3. شمارش مسیرها دقیقاً ۱۳/۱۲/۱/۱ است.
4. هیچ کلید پیشنهادی برای ۱۳ مورد فاقد منبع ساخته نشده است.
5. تنها کاندیدای تازه `25:96 → 1` است و به گزینهٔ موجود payload متصل می‌ماند.
6. ردیف سرخک `25:136` کلید کنونی را نگه می‌دارد و فقط نقص تکرار گزینه را ثبت می‌کند.
7. اثرانگشت‌ها، پیوند منابع و جمع ۱۰۶ ردیفِ صف سازگارند.

## مرز اقدام بعدی

- این دور، بازبینی پژوهشیِ تمام ۲۷ ردیف باقی‌مانده را تکمیل کرده است؛ برای ادامه، دادهٔ منبع یا مجوز تغییر متن/گزینه لازم است.
- هیچ `correct_index` بدون مجوز صریح کاربر تغییر نخواهد کرد.
- اگر مجوز تغییر کلید داده شود، هر کلید تأییدشده در همان دور باید بلافاصله با غنی‌سازی آموزشی همان ردیف همراه باشد.
- اگر مجوز بازنویسی داده شود، فقط با مشخصات حداقلیِ ثبت‌شده در دفتر انجام خواهد شد؛ هیچ دادهٔ غایب از حدس ساخته نمی‌شود.
