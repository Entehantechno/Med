## کنترل مسیر بازیابی منبع

برای همهٔ ۱۳ ردیفِ نیازمند منبع، هر سه جایگاه رسانه‌ای در payload فعلی تهی است.

رسانه‌های booklet محلیِ موجود فقط به نام‌های ۱۴۰۲ و ۱۴۰۳ برچسب خورده‌اند و هیچ نگاشت قابل اثباتی به این ۱۳ شناسه یا نسخهٔ ۰۰۵ ندارند.

جست‌وجوی تاریخچهٔ Git برای سه عبارت نماینده فقط نسخه‌های payload، fixture و گزارش‌های audit را یافت؛ اسکن یا صفحهٔ اولیهٔ قابل‌استخراج پیدا نشد.
