سلام 👋
همهٔ کارهای فنی از قبل انجام شده. تو فقط ۵ کارِ ساده در cPanel انجام می‌دهی.
فایلِ تنظیمات (.env) و کلاینتِ آماده، همه داخلِ همین زیپ هستند.

────────────────────────────────────────────
✅ کارهایی که من از قبل برایت انجام دادم:
────────────────────────────────────────────
• فایلِ .env کامل و آماده است (نیازی به ساختن یا rename نیست)
• کلید امنیتی ورود از قبل پر شده
• محل ذخیرهٔ داده روی «../medschool-data» (بیرونِ پوشهٔ برنامه) تنظیم شده تا با هر آپگرید،
  کل دیتابیس (کاربران، سوالات، وبلاگ، پیشرفت و همه‌چیز) سالم بماند. راهنمای کامل:
  «راهنمای-آپگرید-امن-و-حفظ-دیتابیس.md»
• کلاینت (React) از قبل ساخته شده → روی هاست build لازم نیست
• کلِ فرایند را شبیه‌سازی و تست کردم؛ درست کار می‌کند

────────────────────────────────────────────
👉 کاری که تو باید بکنی (فقط ۵ گام، حدود ۱۰ دقیقه):
────────────────────────────────────────────

گام ۱ — آپلود
  cPanel → File Manager → کنارِ public_html پوشهٔ «medschool» بساز →
  MED-School.zip را داخلش Upload کن → راست‌کلیک → Extract.

گام ۲ — ساختِ اپ Node.js
  cPanel → کادرِ جستجوی بالا: node → «Setup Node.js App» → Create Application
    • Node.js version: 20
    • Application mode: Production
    • Application root: medschool
    • Application URL: دامنه‌ات را انتخاب کن
    • Application startup file:  server/src/index.js   ← دقیقاً همین
  → Create

گام ۳ — نصب پکیج‌ها
  در همان صفحه → دکمهٔ «Run NPM Install» را بزن و صبر کن تمام شود.

گام ۴ — اجرا
  بالای همان صفحه → «Restart».
  حالا دامنه‌ات را در مرورگر باز کن → سایت بالا می‌آید! 🎉

گام ۵ — ورود و امن‌سازی
  با admin / demo وارد شو → فوراً از پروفایل رمز را عوض کن.

────────────────────────────────────────────
⭐ دو نکتهٔ اختیاری ولی خوب:
────────────────────────────────────────────
۱) لینک‌های بی‌نقص: فایلِ .env را با Edit باز کن و فقط این خط را به دامنهٔ
   خودت تغییر بده (سایت بدون این هم کار می‌کند):
       APP_URL=https://دامنهٔ-تو
۲) HTTPS: در cPanel → SSL/TLS Status → برای دامنه‌ات AutoSSL را فعال کن.
