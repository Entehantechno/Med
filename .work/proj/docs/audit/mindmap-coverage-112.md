## ۳) نتیجه‌گیری و پیشنهاد

۳۲۱ نقشه ۲۹ سیستمِ preint/floating را کامل پوشش می‌دهد ولی ۷ تاپیکِ basic فاقدِ سیستمِ مستقل هستند. برای رسیدن به **۱۰۰٪ پوششِ تمامِ مباحثِ تمامِ دروس** پیشنهاد می‌شود ۲۱ نقشه‌یِ جدید برای علومِ پایه + ۷ نقشه برای کاهشِ تراکمِ peds/rheum/heme اضافه شود (مجموع ۲۸ نقشه → ۳۴۹ نقشه).
هر نقشه با رفرنسِ اختصاصی (Gray's آناتومی، Guyton فیزیولوژی، Harper بیوشیمی، Junqueira بافت، Langman جنین، Murray میکروب، Ganong فیزیکِ پزشکی) و گرافِ ۵–۷ گره‌یِ دوزبانه ساخته خواهد شد.
