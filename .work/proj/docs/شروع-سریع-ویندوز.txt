   MED Lab — راهنمای شروع سریع برای ویندوز
══════════════════════════════════════════════════════════════

پیش‌نیاز: فقط Node.js باید نصب باشد. (نیازی به Python یا هیچ ابزار دیگری نیست)
(برای بررسی: cmd را باز کنید و بنویسید:  node -v  ← باید یک عدد نشان دهد)
اگر نصب نیست: از سایت  https://nodejs.org  نسخه LTS را نصب کنید.

──────────────────────────────────────────────────────────────
 مرحله ۱ — خارج کردن از حالت فشرده
──────────────────────────────────────────────────────────────
روی فایل  MED-Lab.zip  راست‌کلیک → Extract All → Extract
پوشه‌ی  medai-fullstack  ساخته می‌شود.

──────────────────────────────────────────────────────────────
 مرحله ۲ — باز کردن Command Prompt داخل پوشه
──────────────────────────────────────────────────────────────
۱) پوشه‌ی  medai-fullstack  را باز کنید (داخلش server و client هست)
۲) روی نوار آدرس بالای پنجره کلیک کنید
۳) بنویسید:  cmd  و Enter بزنید
   → یک پنجره‌ی مشکی باز می‌شود.

──────────────────────────────────────────────────────────────
 مرحله ۳ — اجرای دستورها (یکی‌یکی، بعد از هرکدام Enter)
──────────────────────────────────────────────────────────────
    cd server
    npm install          (فقط بار اول — کمی صبر کنید)
    npm run seed         (فقط بار اول)
    npm start

وقتی این پیام را دیدید یعنی آماده است:
    🧪 MED Lab API running on http://localhost:4000

──────────────────────────────────────────────────────────────
 مرحله ۴ — باز کردن در مرورگر
──────────────────────────────────────────────────────────────
مرورگر را باز کنید و بروید به:
    http://localhost:4000

──────────────────────────────────────────────────────────────
 ورود (رمز همه: demo)
──────────────────────────────────────────────────────────────
    استاد:    teacher   / demo
    مدیر:     admin     / demo
    دانشجو:   40012345  / demo

──────────────────────────────────────────────────────────────
 نکات
──────────────────────────────────────────────────────────────
• پنجره‌ی مشکی را باز نگه دارید تا برنامه روشن بماند.
• برای خاموش کردن: در پنجره‌ی مشکی  Ctrl + C  بزنید.
• دفعات بعد فقط این دو دستور کافی است:
      cd server
      npm start
  (دیگر نیازی به npm install و npm run seed نیست)

──────────────────────────────────────────────────────────────
 اگر با خطا مواجه شدید
──────────────────────────────────────────────────────────────
• "node is not recognized"  → Node.js نصب نیست یا کامپیوتر ری‌استارت نشده.
• "port 4000 already in use" → برنامه از قبل باز است؛ پنجره‌ی قبلی را ببندید.
• صفحه‌ی سفید در مرورگر     → مطمئن شوید پنجره‌ی مشکی هنوز باز است و
                              آدرس دقیقاً  http://localhost:4000  باشد.
