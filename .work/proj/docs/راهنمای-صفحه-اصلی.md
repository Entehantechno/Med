# 🏠 صفحهٔ اصلی (Landing Page)

سایت اکنون یک **صفحهٔ اصلی حرفه‌ای** دارد که اولین چیزی است که بازدیدکنندهٔ واردنشده می‌بیند. این صفحه بر اساس بهترین شیوه‌های صفحات فرود SaaS طراحی شده و در همان نگاه اول به سه سؤال کلیدی پاسخ می‌دهد: «این چیست؟ برای من است؟ چرا اعتماد کنم؟»

## بخش‌ها
1. **Hero** — تیتر مبتنی بر نتیجه، زیرتیتر، دو دکمهٔ اقدام (شروع رایگان / ورود)، نوار آمار، و نمای بصری مسیر یادگیری.
2. **نوار اعتماد** — «مورد اعتماد دانشجویان و اساتید پزشکی».
3. **دو مخاطب** — کارت مجزا برای «داوطلبان پره‌انترنی» و «اساتید و دانشگاه‌ها».
4. **ویژگی‌ها** — ۶ مزیت کلیدی (بیمار مجازی، فلش‌کارت هوشمند، تکرار فاصله‌دار، رقابت، درسنامهٔ QB، دوزبانه/موبایل).
5. **سه گام شروع**.
6. **بخش بازی‌گونه‌سازی** — با نمای لیگ.
7. **نظرات کاربران**.
8. **فراخوان نهایی** + **فوتر**.

## رفتار
- کاربر واردنشده ابتدا **صفحهٔ اصلی** را می‌بیند.
- دکمهٔ **«شروع رایگان»** → فرم ثبت‌نام؛ **«ورود به حساب»** → فرم ورود.
- از فرم ورود، دکمهٔ **«بازگشت به خانه»** به صفحهٔ اصلی برمی‌گردد.
- کاملاً **دوزبانه** (فارسی/انگلیسی)، **تم روشن/تاریک**، و **واکنش‌گرا** (موبایل تا دسکتاپ).
- بدون هیچ منبع خارجی ساخته شده (SVG + گرادیان)، پس سریع بارگذاری می‌شود.
