# 🎛️ راهنمای مدیریت محتوا و تبلیغات (پنل ادمین)

حالا ادمین می‌تواند **بدون دست‌زدن به کد**، متن‌های سایت و تبلیغات هر صفحه را تغییر دهد. این بر اساس بهترین شیوه‌های سیستم‌های مدیریت محتوای مدرن (اصل «یک‌بار بنویس، همه‌جا منتشر کن») طراحی شده است.

---

## ✏️ ۱) مدیریت محتوای سایت (تب «محتوای سایت»)

**کجاست؟** پنل ادمین → دنیای «حساب‌های کاربران» → منوی کناری → **محتوای سایت**

با این تب می‌توانید **همه‌ی متن‌های صفحه‌ی اصلی (لندینگ)** را ویرایش کنید:
تیتر اصلی، زیرتیتر، دکمه‌ها، آمار، معرفی دو مخاطب، شش ویژگی، سه گام، بخش بازی‌گونه، نظرات کاربران، فراخوان نهایی و فوتر.

### چطور کار می‌کند؟
1. **زبان را انتخاب کنید** (فارسی یا English) — هر زبان جداگانه ویرایش می‌شود.
2. بخش موردنظر را باز کنید (مثلاً «بخش اصلی Hero»).
3. متن دلخواه را در کادر بنویسید.
   - زیر هر کادر، **متن پیش‌فرض** نشان داده می‌شود.
   - اگر کادر را **خالی** بگذارید، همان متن پیش‌فرض روی سایت نمایش داده می‌شود.
   - کنار فیلدهای تغییریافته برچسب سبز **«ویرایش‌شده»** ظاهر می‌شود.
4. **«انتشار تغییرات»** را بزنید. تمام! بلافاصله روی سایت اعمال می‌شود.
5. برای بازگشت همه‌چیز به حالت اولیه: **«بازگردانی همه به پیش‌فرض»**.

> 🔎 برای پیدا کردن سریع یک متن، از **کادر جستجو** بالای صفحه استفاده کنید (بین همه‌ی بخش‌ها می‌گردد).

### نکته‌ی فنی (برای اطمینان خاطر)
- متن‌های سفارشی در دیتابیس ذخیره می‌شوند و کد سایت را تغییر نمی‌دهند.
- صفحه‌ی اصلی این متن‌ها را **حتی برای بازدیدکننده‌ی واردنشده** می‌خواند.
- اگر متنی را حذف کنید، سایت خودکار به متن پیش‌فرض دوزبانه برمی‌گردد.

---

## 📢 ۲) مدیریت تبلیغات (تب «مدیریت تبلیغات»)

**کجاست؟** پنل ادمین → دنیای «حساب‌های کاربران» → منوی کناری → **مدیریت تبلیغات**

حالا می‌توانید برای **هر صفحه (جایگاه) جداگانه** تبلیغ بسازید و مدیریت کنید:

| جایگاه | محل نمایش |
|---|---|
| صفحه‌ی خانه‌ی مسیر | خانه‌ی کاربر رقابتی |
| داخل مسیر یادگیری | میان گره‌های مسیر |
| بین درس‌ها | پس از پایان هر درس |
| نوار کناری | کنار صفحه |
| صفحه‌ی مرور | بخش مرور کارت‌ها |
| صفحه‌ی لیگ/رتبه‌بندی | صفحه‌ی لیگ |

### امکانات
- **زبانه‌های جایگاه** بالای صفحه: با کلیک روی هر جایگاه، فقط تبلیغ‌های همان صفحه را می‌بینید (تعداد هر کدام هم نوشته شده).
- هنگام ساخت/ویرایش تبلیغ، یک **پیش‌نمایش زنده** می‌بینید که دقیقاً مثل تبلیغ واقعی است (عنوان، متن، دکمه، رنگ پس‌زمینه).
- برای هر تبلیغ: عنوان و متن دوزبانه، دکمه (CTA)، لینک، رنگ، و وضعیت فعال/غیرفعال.
- آمار **نمایش (impressions)** و **کلیک** هر تبلیغ نشان داده می‌شود.

> 💡 تبلیغات فقط به کاربران رقابتی **غیرپریمیوم** نمایش داده می‌شوند (کاربران پریمیوم تبلیغ نمی‌بینند).

---

## ✅ خلاصه
ادمین حالا می‌تواند «به‌راحتی آب خوردن» متن‌های لندینگ و تبلیغات هر صفحه را تغییر دهد — همه از داخل پنل، بدون نیاز به کدنویسی.
