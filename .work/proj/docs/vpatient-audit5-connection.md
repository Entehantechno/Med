# ممیزی پنجم — تلاش احرازشده با کلید مجاز کاربر

تاریخ: ۲۰۲۶-۰۹-۱۸. مبنا: audit4 / `00f825b`.

کاربر کلید OpenRouter را ارسال و استفاده از آن را صریحاً مجاز کرد. همان مقدار، بدون بازنویسی، در تنظیم `ai` یک کپی خصوصی از دیتابیس آموزشی قرار گرفت. ارائه‌دهنده OpenRouter، آدرس رسمی `https://openrouter.ai/api/v1` و مدل router رایگان `openrouter/free` انتخاب شدند. وضعیت `connected` تا تأیید واقعی false باقی ماند.

کلید در کد، فایل‌های انتشار، `.env.ready`، گزارش یا Git قرار نگرفت. فایل انتقال موقت با دسترسی محدود پس از خواندن حذف شد. دیتابیس خصوصی در مسیر مستثنی از ZIP/Git، با پوشه 0700 و فایل 0600 باقی است. پیش‌نمایش عمومی دارای حساب‌های demo متوقف شد؛ کلید به آن دیتابیس عمومی افزوده نشد. این پیکربندی، تغییر تنظیمات سایت تولیدی کاربر نیست.

## آزمایش انجام‌شده

- سه درخواست واقعی GET به `/api/v1/key` با هدر Authorization حاوی کلید مجاز کاربر؛ هر سه پیش از پاسخ HTTP با `ECONNRESET` شکست خوردند.
- ورود آزمایشی و دو درخواست واقعی به مسیر `/api/exam/patient-reply` برنامه با تنظیمات جدید. مسیر برنامه دو تلاش completion به OpenRouter انجام داد؛ هر دو اتصال شکست خوردند و برنامه به پاسخ محلی برگشت.
- برای این آزمون، لایه انتقال اجازه مقصدی غیر از endpoint رسمی completion نداشت، redirect ممنوع بود و `provider.max_price` صفر، `data_collection: deny` و `max_tokens: 160` اعمال شد. فقط کیس آموزشی مصنوعی استفاده شد.
- پرسش «سلام وقت شما بخیر» پاسخ «سلام دکتر.» گرفت و سؤال «سلام، از کی شروع شده؟» پاسخ زمان شروع ثبت‌شده گرفت؛ هر دو `source: mock` و `providerFailed: true` داشتند. HTTP 200 برنامه به معنی HTTP موفق OpenRouter نیست.

تعداد completion زنده: **صفر**. اعتبار کلید نیز تأیید یا رد نشده است؛ قطع شبکه پیش از پاسخ احراز هویت رخ داد. دیگر «نبود مقدار کلید» مانع این آزمایش نیست؛ اتصال HTTPS محیط به مقصد همچنان مشکل دارد. مجوز دسترسی شبکه محیط باید توسط میزبان Arena بررسی شود. تکرار درخواست با همان تنظیمات به‌تنهایی تضمین رفع ECONNRESET نیست.

گزارش ماشینی بدون کلید: `docs/vpatient-audit5-connection.json`.

## محدودیت انتشار

هیچ کد، تست، بانک سؤال یا تنظیم انتشار نسبت به audit4 تغییر نکرد. مجموعه تست کامل در این دور دوباره اجرا نشد. این بسته صرفاً دو گزارش جدید دارد؛ کلید خصوصی داخل آن نیست. باگ‌های بالینی گزارش‌های قبل هنوز بازند و هیچ مدل رایگان رتبه‌بندی نشده است.

چون کلید در چت ارسال شده، تعویض آن پس از آزمایش توصیه می‌شود. این توصیه، انکار مالکیت یا مجوز کاربر نیست.
