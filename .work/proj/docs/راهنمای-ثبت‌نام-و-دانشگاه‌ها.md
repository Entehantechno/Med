# 🔐 ثبت‌نام کاربران + 🏛️ مدیریت دانشگاه‌ها

## ۱) ثبت‌نام کاربران رقابتی (Learners)

کاربران اکنون سه راه برای ورود دارند:

### الف) ثبت‌نام با ایمیل
- در صفحهٔ ورود، «ثبت‌نام برای مسیر پره‌انترنی» → نام، **ایمیل**، رمز و استان.
- اگر سرویس ایمیل (SMTP) تنظیم شده باشد، **ایمیل تأیید** ارسال می‌شود؛ کاربر روی لینک می‌زند و حساب فعال می‌شود.
- اگر SMTP تنظیم نشده باشد (مثل اجرای لوکال)، حساب **به‌صورت خودکار تأیید** می‌شود تا کاربر گیر نکند.
- ورود بعدی با **ایمیل یا نام کاربری** ممکن است.

### ب) ورود با گوگل (Google Sign-In)
- دکمهٔ رسمی «ادامه با گوگل» زیر فرم ورود نمایش داده می‌شود — **فقط وقتی که کلید گوگل تنظیم شده باشد**.
- برای فعال‌سازی: در `.env` سرور مقدار `GOOGLE_CLIENT_ID` را بگذارید (از [Google Cloud Console](https://console.cloud.google.com/apis/credentials) بسازید و دامنه‌تان را در «Authorized JavaScript origins» اضافه کنید).
- اگر کلید نباشد، دکمه به‌طور خودکار پنهان می‌شود و بقیهٔ ورود کار می‌کند.

> این دو روش فقط برای **کاربران رقابتی (learner)** است. اساتید و دانشجویان دانشگاهی را ادمین اضافه می‌کند.

## ۲) مدیریت دانشگاه‌ها (ادمین)

از **پنل مدیریت → حساب‌های دانشگاهی → دانشگاه‌ها**:
- **ساخت دانشگاه** (نام فارسی/انگلیسی، شهر، کد خودکار).
- مشاهدهٔ تعداد **اساتید و دانشجویان** هر دانشگاه.
- ویرایش و حذف (حذف فقط وقتی دانشگاه عضوی ندارد).

### افزودن استاد/دانشجو به دانشگاه
هنگام ساخت یا ویرایش کاربر (در بخش مدیریت کاربران)، اگر نقش **استاد** یا **دانشجو** باشد، یک منوی کشویی **«دانشگاه»** ظاهر می‌شود تا او را به دانشگاه مربوطه متصل کنید. نام دانشگاه در لیست کاربران کنار هر فرد نمایش داده می‌شود.

## ۳) تنظیمات محیطی (اختیاری)

فایل `server/.env` (نمونه در `.env.example`):
```
# ورود با گوگل
GOOGLE_CLIENT_ID=xxxxx.apps.googleusercontent.com

# ارسال ایمیل تأیید (SMTP)
APP_URL=https://yourdomain.com
SMTP_HOST=smtp.yourprovider.com
SMTP_PORT=587
SMTP_USER=...
SMTP_PASS=...
MAIL_FROM=MED School <no-reply@yourdomain.com>
```
هر دو **اختیاری**‌اند؛ بدون آن‌ها هم سایت کامل کار می‌کند (ثبت‌نام ایمیلی بدون تأیید، و بدون دکمهٔ گوگل).
