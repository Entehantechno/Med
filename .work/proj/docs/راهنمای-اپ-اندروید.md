# 📱 راهنمای ساخت اپ اندروید (TWA) — کافه‌بازار و گوگل‌پلی

این راهنما قدم‌به‌قدم توضیح می‌دهد چطور از سایتِ MED School یک **اپ اندرویدِ واقعی** بسازی و روی **کافه‌بازار** و **گوگل‌پلی** منتشر کنی — بدون بازنویسی برنامه.

---

## TWA یعنی چه؟
**TWA (Trusted Web Activity)** یعنی همین سایتِ PWA شما داخل یک پوستهٔ اندرویدی اجرا می‌شود — **بدون نوار مرورگر**، تمام‌صفحه، دقیقاً مثل یک اپ بومی. مزیت‌ها:
- یک کدِ واحد؛ هر تغییری در سایت، فوراً در اپ هم دیده می‌شود (نیازی به آپدیت مجدد اپ نیست).
- سبک (چند صد کیلوبایت)، سریع، و با پشتیبانی از نوتیفیکیشن و نصب روی صفحهٔ خانه.

> پیش‌نیاز: سایت باید روی یک **دامنهٔ HTTPS واقعی** مستقر باشد (مثلاً `https://medschool.ir`). فایل استقرار در «راهنمای-استقرار.md» است.

---

## پیش‌نیازها (روی ویندوز)
1. **Node.js** (نسخهٔ ۱۸ یا بالاتر) — از nodejs.org
2. **JDK 17** — از adoptium.net (Temurin)
3. **Android SDK** — Bubblewrap در اولین اجرا خودش آن را نصب می‌کند؛ فقط «Yes» بزن.

---

## گام ۱ — نصب Bubblewrap
Bubblewrap ابزار رسمی گوگل برای ساخت TWA است. در ترمینال (CMD یا PowerShell):

```
npm install -g @bubblewrap/cli
```

---

## گام ۲ — ساخت پروژهٔ اپ
در یک پوشهٔ خالی، از روی manifestِ سایت اپ را بساز:

```
npx @bubblewrap/cli init --manifest https://medschool.ir/manifest.webmanifest
```

سؤال‌هایی می‌پرسد؛ مقادیر پیشنهادی:
- **Domain:** `medschool.ir` (دامنهٔ واقعی خودت)
- **Application name:** `MED School — آموزش هوشمند پزشکی`
- **Short name:** `MED School`
- **Application ID (package):** `ir.medschool.twa` ← این را یادداشت کن (در پنل ادمین لازم می‌شود)
- **Display mode:** `standalone`
- **Orientation:** `portrait`
- **Status bar color:** `#26527a`

> می‌توانی به‌جای پاسخ دستی، فایلِ آمادهٔ `android/twa-manifest.json` را کنار پروژه بگذاری و مقادیر `host` را با دامنهٔ خودت جایگزین کنی.

---

## گام ۳ — ساخت APK و AAB + کلید امضا
```
npx @bubblewrap/cli build
```
این دستور:
- یک **کلید امضا** (`android.keystore`) می‌سازد — 🔴 **این فایل و رمزش را حتماً نگه دار و گم نکن** (برای آپدیت‌های بعدی حیاتی است).
- خروجی می‌دهد:
  - `app-release-signed.apk` → برای **کافه‌بازار**
  - `app-release-bundle.aab` → برای **گوگل‌پلی**

---

## گام ۴ — گرفتن اثرانگشت SHA-256 (خیلی مهم)
اپ باید ثابت کند که «صاحبِ» سایت است تا نوار مرورگر حذف شود. برای این کار، اثرانگشتِ کلید امضا را بگیر:

```
keytool -list -v -keystore android.keystore -alias medschool
```
(رمز را وارد کن.) در خروجی، خطی به شکل زیر پیدا کن:
```
SHA256: AB:CD:EF:...:99   (۹۵ کاراکتر، جفت‌های hex با دونقطه)
```
این رشته را کامل کپی کن.

---

## گام ۵ — ثبت اثرانگشت در پنل ادمین (تأیید مالکیت)
1. وارد **پنل مدیریت** شو → بخش **«سیستم»** → **«اپ اندروید (TWA)»**.
2. **«فعال‌سازی تأیید اپ»** را روشن کن.
3. **نام پکیج** را وارد کن (همان `ir.medschool.twa`).
4. اثرانگشتِ **SHA-256** را در کادر بگذار (هر خط یک اثرانگشت).
5. **ذخیره** کن.

حالا سایت به‌صورت زنده این فایل را منتشر می‌کند:
```
https://medschool.ir/.well-known/assetlinks.json
```
این همان چیزی است که اندروید برای حذف نوار مرورگر بررسی می‌کند. ✅ (در پنل، پیش‌نمایش این فایل را می‌بینی.)

> 📌 **نکتهٔ گوگل‌پلی:** اگر از «Play App Signing» استفاده کنی، گوگل کلید خودش را هم اضافه می‌کند. در آن صورت **دو** اثرانگشت داری (کلید خودت + کلید گوگل) — **هر دو** را در پنل وارد کن. کافه‌بازار از کلید خودت استفاده می‌کند.

---

## گام ۶ — انتشار
### کافه‌بازار
1. به پنل توسعه‌دهندهٔ کافه‌بازار برو → «افزودن برنامه».
2. فایل `app-release-signed.apk` را بارگذاری کن.
3. آیکون، تصاویر، و توضیحات را پر کن (از `client/public/icon-512.png` استفاده کن).
4. ارسال برای بررسی.

### گوگل‌پلی
1. به Google Play Console برو → «Create app».
2. فایل `app-release-bundle.aab` را در یک Release بارگذاری کن.
3. اطلاعات فروشگاه + سیاست حریم خصوصی را پر کن.
4. ارسال برای بررسی.
