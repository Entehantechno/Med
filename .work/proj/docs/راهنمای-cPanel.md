# 🌐 راهنمای گام‌به‌گام استقرار روی cPanel

این راهنما مخصوص کسی است که داخل **cPanel** است و می‌خواهد سایت را آنلاین کند.

## ⚠️ مهم‌ترین نکته را اول بخوان
سایتِ MED School یک برنامهٔ **Node.js** است (نه یک سایت PHP/وردپرس معمولی). پس روی cPanel فقط در صورتی مستقیم اجرا می‌شود که هاستت **Node.js** را پشتیبانی کند.

### چطور بفهمم هاستم Node.js دارد؟
۱. وارد cPanel شو.
۲. در کادرِ **جستجوی بالای صفحه**، تایپ کن: `node`
۳. اگر گزینه‌ای به نام **«Setup Node.js App»** یا **«Node.js Selector»** دیدی → **مسیر A** را برو.
۴. اگر هیچ‌چیزی درباره‌ی Node.js نبود → **مسیر B** را بخوان.

# ✅ مسیر A — هاستت Node.js دارد (بهترین حالت)

## گام ۱: فایل‌ها را آپلود کن
۱. در cPanel → **File Manager** را باز کن.
۲. یک پوشهٔ جدید بساز، مثلاً: `medschool` (خارج از `public_html`، مثلاً کنارش).
۳. فایل `MED-School.zip` را داخل آن پوشه **Upload** کن.
۴. روی فایل زیپ راست‌کلیک → **Extract** (استخراج).

## گام ۲ — تنظیمات (`.env`) — هیچ کاری لازم نیست ✅
فایل `.env.ready` داخل زیپ از قبل برای **medschool.ir** آماده است (`APP_URL=https://medschool.ir`، حالت production).
در اولین اجرا، سرور خودش آن را به `.env` کپی می‌کند و یک `JWT_SECRET` تصادفیِ مخصوص همین هاست می‌سازد.
- دیتابیس و آپلودها به‌طور خودکار در پوشهٔ `~/medschool-data` (کنارِ پوشهٔ برنامه، بیرون از کد) ساخته می‌شود؛ پس با آپدیت‌های بعدی پاک نمی‌شود.
- فقط اگر دامنه‌ات چیز دیگری است، `.env.ready` را باز کن و `APP_URL` را عوض کن.

## گام ۳: اپ Node.js را بساز
۱. cPanel → **Setup Node.js App** → **Create Application**.
۲. مقادیر:
   - **Node.js version:** جدیدترین نسخهٔ ۱۸ یا بالاتر (مثلاً 20).
   - **Application mode:** `Production`
   - **Application root:** مسیر پوشه‌ای که اکسترکت کردی (مثلاً `medschool`).
   - **Application URL:** دامنه‌ات را انتخاب کن.
   - **Application startup file:** `app.cjs`  ← (نه `server/src/index.js`؛ آن فایل ES-Module است و Passenger نمی‌تواند مستقیم اجرایش کند)
۳. **Create** را بزن.

## گام ۴: نصب پکیج‌ها (فقط یک کلیک)
> ✅ **خبر خوب:** بخشِ کلاینت (React) از قبل ساخته شده و داخلِ همین زیپ (`client/dist`) قرار دارد. پس **لازم نیست** روی هاست `build` بزنی — این هم سریع‌تر است و هم رمِ هاستت را اشغال نمی‌کند.

۱. در همان صفحهٔ Node.js App، فقط دکمهٔ **Run NPM Install** را بزن و صبر کن تمام شود.
   - این دستور به‌طور خودکار پکیج‌های سرور را هم نصب می‌کند (به‌لطفِ `postinstall`). کارِ دیگری لازم نیست.
   - نیازی به Terminal نداری. (اگر Terminal داری و ترجیح می‌دهی: `cd ~/medschool && npm install` هم دقیقاً همین کار را می‌کند.)

## گام ۵: راه‌اندازی مجدد و باز کردن سایت
۱. در صفحهٔ Node.js App → **Restart**.
۲. دامنه‌ات را در مرورگر باز کن. سایت باید بالا بیاید! 🎉
   - بارِ اول، دیتابیس و محتوای نمونه به‌طور خودکار ساخته می‌شود (فقط همان یک‌بار). دفعاتِ بعد، دیتای کاربران دست‌نخورده می‌ماند.

### ورود مدیر (پیش‌فرض)
- نام کاربری: `admin` — رمز: `demo`
- 🔴 **بلافاصله بعد از ورود، رمز را عوض کن.**

# ❌ مسیر B — هاستت Node.js ندارد (هاست اشتراکیِ فقط‌PHP)

صادقانه: این سایت روی هاستِ فقط‌PHP **اجرا نمی‌شود** (چون به Node.js نیاز دارد). سه راه‌حل داری:

### راه‌حل ۱ (پیشنهادی): یک VPS ارزان بگیر
یک سرور مجازیِ ساده (ماهانه چند ده هزار تومان) که Docker یا Node.js دارد. بعد طبق فایل **`راهنمای-استقرار.md`** فقط یک دستور می‌زنی و کارت تمام است (HTTPS هم خودکار می‌گیرد).

### راه‌حل ۲: از پلن هاستت بپرس
با پشتیبانیِ هاستت تماس بگیر و بپرس: **«آیا پلن من از Node.js پشتیبانی می‌کند یا می‌توانم ارتقا دهم؟»** خیلی از هاست‌های ایرانی پلنِ Node.js دارند.

### راه‌حل ۳: هاست مخصوص Node.js
سرویس‌هایی مثل Liara، Render، Railway (یا هاست‌های ایرانیِ Node.js) مخصوص همین کارند و راه‌اندازی‌شان ساده است.
