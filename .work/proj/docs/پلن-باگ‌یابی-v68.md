## فهرست باگ‌ها — از بزرگ به کوچک

### سطح ۱ — امنیت / از دست رفتن داده
1. **JWT_SECRET ثابت در `.env.ready` داخل مخزن عمومی GitHub** — هرکس که زیپ یا مخزن را دارد می‌تواند برای هر کاربری (از جمله admin) توکن معتبر بسازد. باید هنگام اولین اجرا رمز تصادفی ساخته شود، نه اینکه از زیپ کپی شود.
2. **نوشتن دیتابیس اتمیک نیست** (`db.js → persistNow`): `writeFileSync(DB_PATH, …)` روی خودِ فایل. قطع برق/کرش وسط نوشتنِ فایل ۸۰ مگابایتی = دیتابیس خراب. راه‌حل: نوشتن در `medlab.db.tmp` + `fsync` + `rename`.
3. **صادرات `users` شامل `password_hash` و `token_ver`** (`GET /api/admin/export/users`) — نقش `support`/`content_manager` با مجوز `learn.data` هش رمز همه را می‌گیرد.
4. **کدهای دعوت/گواهی/صندلی با `Math.random`** (کلاس `MED-1000..9999`، دانشگاه، چالش، گواهی، seat-code، referral) — قابل حدس؛ باید `crypto.randomInt`.
5. **تزریق هدر / کرش در CSV** (`reports.js /export.csv`): `type` یا `examId` کاربر مستقیم داخل `Content-Disposition` → با `"` یا نویسهٔ غیر-ASCII خطای ۵۰۰ (تأیید شد). همچنین `questionnaires.js` (`template_key`).

### سطح ۲ — منطق بازی / تقلب
6. **`correct > total` پذیرفته می‌شود** در `lesson/:id/finish`، `exam-sim/:id/finish`، `challenge/:id/submit`، `legendary/:id/finish` → با یک POST مقدار `correct=1000000` گرفتم **۲۰٬۰۰۰٬۰۱۰ XP** و احتمال قبولی ۹۹٪ (تأیید شد). چک‌پوینت و رویداد (event) درست کلمپ می‌کنند؛ بقیه نه. راه‌حل: `correct = min(correct, total)` و `total = min(total, تعداد کارت‌های واقعیِ همان درس/آزمون)`.

### سطح ۳ — پایداری / تست
7. **تست `re-activates a lesson …` قرمز** — به‌خاطر باقی‌ماندن ردیف‌های `admin_deleted` (tombstone) از اجرای قبلی؛ `seed --force` جدول `admin_deleted` را پاک نمی‌کند → اسکریپت seed اصلاح شود.
8. **`fetch` بدون timeout** به زرین‌پال (`zarinpal.js`) و JWKS گوگل — یک درخواستِ آویزان، درخواست کاربر را برای همیشه نگه می‌دارد. افزودن `AbortSignal.timeout(15000)`.

### سطح ۴ — کیفیت کد / UI
9. **کلیدهای تکراری** در `masterbank-md.js` (خط ۲۰۳–۲۰۴: `اسیبشناسی اختصاصی`، `روانپزشکی`) — بی‌اثر ولی eslint error.
10. **۱۳ دستور `eslint-disable` بلااستفاده** و ۷۰۷ متغیر بلااستفاده — پاکسازیِ سبک (فقط disableها؛ متغیرها دست نمی‌خورد).
11. **RTL**: فیلد رمز عبور بدون `dir="ltr"` (Profile.jsx ×۳، Admin.jsx ×۲) — کاراکترهای رمز در حالت فارسی به‌هم می‌ریزند.
12. **Service Worker**: پاسخ کش‌شدهٔ API فقط با `resp.ok` ذخیره می‌شود ✓، API auth/pay/admin کش نمی‌شود ✓ — مشکلی نیست. فقط مسیر `/api/learn/me` و `/api/flags` بعد از logout در کش می‌مانند؛ هنگام logout کش `api` پاک شود.
