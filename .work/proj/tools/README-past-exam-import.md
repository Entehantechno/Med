# راهنمای ورود سؤال‌های سال‌های گذشته

این ابزار برای محتوایی است که شما مجوز استفاده/بازنشر آن را دارید یا منبع رسمی/قابل اتکا برای استفاده آموزشی آن مشخص است.

## فایل‌ها

- `past-exam-csv-template.csv`: قالب ورود سؤال‌ها
- `convert-past-exam-csv-to-import-json.mjs`: تبدیل CSV به JSON مناسب پنل import مسیر رقابتی

## تبدیل CSV به JSON

```bash
node tools/convert-past-exam-csv-to-import-json.mjs tools/past-exam-csv-template.csv /tmp/past-exam-import.json
```

سپس محتوای JSON خروجی را در پنل ادمین وارد کنید:

مسیر:

```text
ادمین → رقابتی → مدیریت مسیر → ورود سؤال‌های رسمی/سال‌های قبل
```

اول Dry-run بزنید. سپس اگر نتیجه درست بود Commit کنید.

## منطق سیستم

- سؤال‌های غیرتکراری و با route مناسب وارد مسیر رقابتی می‌شوند.
- سؤال‌های تکراری/overflow وارد بانک پریمیوم می‌شوند.
- هر درس حداکثر ۱۵ سؤال می‌گیرد.
- metadata منبع، سال، فصل، شماره سؤال و license ثبت می‌شود.
